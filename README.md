# Veda Technology Business & Services Website

## Project Description

A professional and responsive business website built using HTML5, CSS3,
and JavaScript. The website introduces technology programs, IT services,
internship information, frequently asked questions, and contact options.

## Objectives

- Create a responsive business website.
- Practice HTML page structure and semantic elements.
- Learn CSS layouts, Flexbox, Grid, and media queries.
- Add interactive features using JavaScript.
- Understand basic SEO and website navigation.
- Practice organizing files for Git and GitHub.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub
- Google Fonts

## Features

- Professional homepage and navigation.
- About section.
- Technology program cards.
- Program category filters.
- IT and digital services section.
- Internship and training information.
- Interactive FAQ accordion.
- Contact form with browser-side validation.
- Responsive mobile navigation.
- Back-to-top button.
- Basic SEO metadata.
- Responsive desktop, tablet, and mobile layouts.
